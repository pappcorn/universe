# Changelog

All notable changes to `@pappcorn/youtube-mcp`. This project follows
[semantic versioning](https://semver.org/).

## 0.1.0

### Added

- **First release.** Read the transcript of a YouTube video from its
  captions, uploaded by the channel or auto-generated by YouTube. No API key,
  no Google account, nothing to configure.
- **`youtube_get_transcript`**: title, channel, duration and the caption
  language actually used, then the text as paragraphs or with `[mm:ss]`
  timestamps. A preferred language matches regional variants (`es` finds
  `es-419`); when it doesn't exist, the result says so and lists what does.
  Without one, the language spoken in the video is used. Long transcripts come
  in parts, with the offset to continue from.
- **`youtube_list_transcript_languages`**: the caption languages a video has.
- Both tools are annotated read-only.
- **Every link shape people paste**: `watch?v=`, `youtu.be`, Shorts, `/embed`,
  `/live`, mobile, music and no-cookie hosts, or a bare video id.
- **Plain-language failures** for a video with no captions, a video YouTube
  only shows to signed-in people, a live stream, rate limiting and network
  errors. No retries and no workarounds: when YouTube says no, the connector
  says so and stops.
- **A one-click Claude Desktop extension** (`youtube-mcp.mcpb`), built from
  the same bundle the plugin runs, for Claude Desktop and Cowork.
- **A CLI**, `pappcorn-youtube`: `transcript` and `languages`.
