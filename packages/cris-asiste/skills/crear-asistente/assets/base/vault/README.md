# Tu memoria

Esta carpeta es la memoria de tu asistente y es tuya. Archivos de texto en carpetas normales, sin base
de datos y sin ataduras. Ábrela con Obsidian, con el Finder o con cualquier editor de texto.

Está ordenada con el método PARA:

| Carpeta         | Qué va aquí                                             |
| --------------- | ------------------------------------------------------- |
| `0. Inbox/`     | Lo que aún no está ordenado. Las notas del día también. |
| `1. Projects/`  | Cosas hacia las que trabajas y que van a terminar       |
| `2. Areas/`     | Responsabilidades continuas que no terminan             |
| `3. Resources/` | Referencia que vale la pena guardar                     |
| `4. Archives/`  | Terminado o dormido: se guarda, no se borra             |

No tienes que ordenar nada tú. Cuéntale algo a tu asistente y va a donde corresponde.
