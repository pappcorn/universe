El catálogo

Seis plugins, un solo marketplace.

Todo se instala desde pappcorn-plugins, el marketplace de PappCorn para Claude Code. Los conectores también corren en cualquier cliente MCP.

  • gmail-mcp
    Conector · gratis

    Lee, busca, organiza y envía correo desde tu propia cuenta. Siempre te confirma antes de enviar y nunca borra nada.

  • gsheets-mcp
    Conector · gratis

    Consulta y edita las hojas de cálculo compartidas contigo, sin cargar el archivo completo. Cada cambio se confirma antes de escribir.

  • whatsapp-mcp
    Conector · gratis

    Envía mensajes y plantillas desde tu propio número de negocio, por la API oficial de Meta.

  • cris-asiste
    Skills · gratis

    Tres skills con las que Cris te acompaña a configurar tu IA: crear un agente, enseñarle una tarea a tu Claude y armar tu asistente personal. Funcionan también en el chat de Claude.

  • best-practices-git
    Skills · gratis

    Cómo trabaja con git un equipo que trabaja con agentes: commits, pull requests y ramas en paralelo.

  • product-team
    Agentes · con licencia

    El equipo de producto de seis agentes de PappCorn. Para pedir acceso, escríbenos a cris@pappcorn.com.

Tus credenciales son tuyas. Cada conector usa tu propia app y tu propia cuenta, y la credencial nunca sale de tu máquina. PappCorn no aloja nada ni pasa nada por sus servidores. Los conectores actúan solo cuando tú se lo pides.

Skills gratis · cris-asiste

Configura tu propia IA.

Tres skills con las que Cris te acompaña a configurar tu IA en vez de solo usarla. Te entrevistan, proponen y escriben contigo; al final tienes algo tuyo que entiendes y puedes cambiar.

/crear-agente
Un ayudante con un trabajo claro, una fuente de información y unos límites. Descargar .zip · Guía
/crear-skill
Enséñale a tu Claude una tarea que repites, para no explicarla cada vez. Descargar .zip · Guía
/crear-asistente
Tu asistente personal, con tu nombre para él, tus metas y una memoria en una carpeta tuya. Necesita Claude Code. Descargar .zip · Guía

En el chat de Claude, sube cada .zip en Customize → Skills → + → Upload a skill (necesita activada la opción Code execution and file creation). En Claude Code se instalan las tres de una vez:

Instala cris-asiste · en Claude Code 
/plugin marketplace add pappcorn/universe
/plugin install cris-asiste@pappcorn-plugins
Los conectores

Dale poderes reales a tu asistente.

Los conectores se instalan como plugins en Claude Code (y corren en cualquier cliente MCP). Instalarlos toma dos comandos:

Instala desde el marketplace · en Claude Code 
/plugin marketplace add pappcorn/universe
/plugin install gmail-mcp@pappcorn-plugins

Cada conector necesita una configuración de cuenta única (~15 minutos, guiada paso a paso, en inglés): Gmail · Google Sheets · WhatsApp. El catálogo completo vive en github.com/pappcorn/universe.
