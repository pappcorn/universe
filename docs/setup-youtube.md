# Install the YouTube transcripts connector

`youtube-mcp` lets Claude read the transcript of a YouTube video. You paste a
link, Claude gets the text from the video's captions, and then it can
summarize it, pull out quotes, answer questions about it or translate it.

There is nothing to set up: no Google account, no API key, no app to create.
It reads the same public captions you see when you press **CC** on a video,
from your own computer.

**What it can't do (yet).** It reads captions only. A video with no captions
at all (neither uploaded by the channel nor auto-generated by YouTube) gets a
clear message saying so; the connector does not download or listen to the
audio. Videos YouTube only shows to signed-in people (age-restricted, private,
members-only) are out of reach too, because the connector signs in to
nothing.

## Pick the path for your app

| You use                              | Install                                                           | Needs on your computer   |
| ------------------------------------ | ----------------------------------------------------------------- | ------------------------ |
| **Claude Desktop**, including Cowork | [the one-click extension](#claude-desktop-and-cowork)             | nothing                  |
| **Claude Code**                      | [the plugin](#claude-code)                                        | Node.js 20 or newer      |
| **Both**                             | the extension in Claude Desktop **and** the plugin in Claude Code | Node.js, for Claude Code |

Both paths run the same connector, built from the same file. Using both apps?
Install each in its own app, once. Don't also add the plugin inside Claude
Desktop: you would get the same two tools twice.

## Claude Desktop and Cowork

A Desktop extension (`.mcpb` file) installs in a few clicks. Claude Desktop
brings its own runtime for it, so there is nothing else to install.

1. **Download** the extension:
   [youtube-mcp.mcpb](https://pappcorn.github.io/universe/extensions/youtube-mcp.mcpb).
   It is rebuilt from this repository every time it changes, so the link
   always gives the current version. Each released version is also attached
   to its [GitHub Release](https://github.com/pappcorn/universe/releases).
2. **Open it.** Double-click the downloaded file, or drag it onto the Claude
   Desktop window. If neither opens it, go to **Settings → Extensions →
   Advanced settings → Install Extension…** and pick the file.
3. Claude shows a preview with the extension's name and its two tools.
   Select **Install** and confirm.
   Claude Desktop may say the extension is not signed: that is expected for
   this open-source build. The file's contents are in this repository.
4. **Optional:** in the extension's settings, set a preferred caption language
   (`es`, `en`, `pt-BR`, …). Leave it empty and each video comes in the
   language it is spoken in.
5. Open a **new** chat or Cowork task and try it:
   _"Summarize this video: https://youtu.be/…"_.

The extension runs on your computer, not in Cowork's sandbox, so it reaches
YouTube with your normal internet connection. On a work account, an
administrator can turn Desktop extensions off; if the **Install** button is
missing, that is the reason.

## Claude Code

Add the catalog once, then install:

```
/plugin marketplace add pappcorn/universe
/plugin install youtube-mcp@pappcorn-plugins
```

Or from a terminal:

```bash
claude plugin marketplace add pappcorn/universe
claude plugin install youtube-mcp@pappcorn-plugins
```

The plugin asks for one optional setting, the preferred caption language;
leave it empty to get each video in its spoken language. Start a new session,
check `/mcp` lists `plugin:youtube-mcp:youtube` as connected, and paste a link.

The plugin runs the connector with the `node` on your machine. Check you have
it with `node --version` (20 or newer). If you don't, install the LTS version
from [nodejs.org](https://nodejs.org).

### Without the plugin

From npm, in Claude Code or any MCP client (needs Node.js too):

```bash
claude mcp add --scope user youtube -- npx -y @pappcorn/youtube-mcp
```

## Using it

You don't need to name the tools. Paste a link and say what you want:

- _"Transcribe this: https://www.youtube.com/watch?v=…"_
- _"Give me the three main ideas of this Short: https://youtube.com/shorts/…"_
- _"Find the moment where they talk about prices, with the timestamp."_
- _"What languages does this video have subtitles in?"_

Any link shape works: `youtube.com/watch?v=…`, `youtu.be/…`, Shorts,
`/embed/…`, `/live/…`, mobile and music links, or the bare 11-character
video id. Channel and playlist links don't: they are not one video.

The two tools, both read-only:

| Tool                                | What it returns                                                                                                                                     |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `youtube_get_transcript`            | Title, channel, duration, the caption language used (and whether YouTube auto-generated it), then the text, as paragraphs or with `[mm:ss]` stamps. |
| `youtube_list_transcript_languages` | The caption languages the video has, uploaded and auto-generated.                                                                                   |

Long videos come back in parts of about 80,000 characters (roughly an hour
and a half of speech). The result tells Claude how to ask for the next part.

**Auto-generated captions** are YouTube's speech recognition. They are usually
good, but they can mishear names, brands and numbers. The connector flags them
so Claude treats those details with care.

## When it says no

| Message                                             | What it means                                                                                                                                            |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _"… has no captions on YouTube …"_                  | The video has no captions of any kind. Nothing to read. (Common on very short or music-only videos.)                                                     |
| _"… only shows this video to a signed-in person …"_ | Age-restricted, private or members-only, or YouTube is asking your network to prove it is a person. Open it in the browser; the connector won't sign in. |
| _"… limiting requests from this network …"_         | Too many requests in a short time. Wait an hour.                                                                                                         |
| _"… live right now …"_                              | Captions of a live stream appear after it ends.                                                                                                          |
| _"… no captions in "fr"; used en instead …"_        | Not an error: the language you asked for doesn't exist for that video, so you got another and the list of what exists. Claude can translate.             |

## Privacy

The connector talks to `www.youtube.com` and nothing else. It sends the
video id, the same request the YouTube app makes to open a video, and
downloads the caption file. It stores nothing, logs nothing, and has no
account, key or cookie to send. YouTube sees the request come from your
computer, as it would if you opened the video, under
[Google's privacy policy](https://policies.google.com/privacy).

## Future

Transcribing videos that have no captions would mean downloading the audio and
running speech recognition on your computer. That is heavier (a speech model
of several hundred megabytes) and is not in this version.
